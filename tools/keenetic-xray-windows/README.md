# Обновление Xray на Keenetic с Windows

Для Keenetic с Entware и XKeen, где Xray установлен в `/opt/sbin/xray` и работает через `/opt/etc/init.d/S24xray`. Поддерживаются процессоры ARM64 и ARMv7. Скрипт обновляет только Xray до **26.10.31** и не обновляет прошивку роутера или VPN-сервер.

1. Подключитесь по AnyDesk к компьютеру, который находится в сети этого роутера.
2. Распакуйте архив целиком в отдельную папку и запустите `Start-Update.cmd` двойным щелчком.
3. Проверьте предложенный адрес шлюза или введите адрес роутера. Укажите логин SSH Entware (обычно `root`) и его порт (обычно `222`; иногда другой).
4. При первом подключении SSH спросит подтверждение ключа устройства. Сверьте его с администратором. Когда появится запрос пароля, введите пароль SSH: символы не отображаются. Пароль не нужно сообщать в чат.
5. Дождитесь сообщения `SUCCESS` и проверьте VPN на компьютере и телефоне. Если появится ошибка, передайте администратору текст окна, не отправляя пароль.

На компьютере нужен встроенный Windows OpenSSH Client. На роутере нужны работающий SSH, Entware, XKeen, `curl`, `unzip`, `jq` и `sha256sum`; один профиль VLESS REALITY в `04_outbounds.json`; доступ к GitHub и хотя бы одному из тестовых сайтов через VPN. Если условия не выполнены, скрипт завершится до замены Xray.

Скрипт сверяет SHA-256 официального архива, проверяет конфигурацию и пробное VPN-подключение новой версией до изменения. После замены он перезапускает Xray и повторяет проверку. При ошибке либо обрыве операции предусмотрен откат; предыдущий бинарник хранится в `/opt/var/backups/xray-update/` на роутере. Конфигурацию, профили и учётные данные скрипт не меняет и не выводит. При запуске изменение бинарника кратковременно прервёт VPN.

На Windows с активным сторонним VPN автоматически определённый шлюз может оказаться неверным — в этом случае укажите локальный адрес Keenetic вручную. Обновление клиента само по себе не исправляет уязвимости ядра VPN-сервера.
